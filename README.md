# Quento.eu Standalone Replica

Self-contained standalone HTML replica of [https://www.quento.eu/](https://www.quento.eu/), reverse-engineered from its HubSpot CMS React Islands (`@projects/quento-theme`) and network capture.

## Files

- `index.html` / `quento-standalone.html` — Complete standalone single-file HTML replica with all styles (`main.css`, `Lato`), custom fonts (`MontBlancRegular`, `MontBlancSemiBold`, `MontBlancBold`), SVG icons, Lottie vector frames, and images embedded as Base64 `data:` URIs, plus a self-contained vanilla JS runtime for sticky header, mobile offcanvas drawer/accordions, footer accordions, and scroll animations.

## Usage

Open `index.html` or `quento-standalone.html` directly in any browser:

```bash
open quento-standalone.html
```
